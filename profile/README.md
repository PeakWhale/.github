# PeakWhale™

> *Let technology fall quiet, so people can follow the whispers of their dreams.*

**PeakWhale™** is an open-source initiative founded by [Aditya Rao (Addy) Kaveti](https://adrkv.github.io) to build practical, local-first, explainable AI and machine learning baselines for business operations.

Every PeakWhale™ project runs locally on your own hardware or servers, explains its outputs in plain English, and ships with a command-line interface (CLI), an HTTP API, and a Model Context Protocol (MCP) server.

## Open-Source Projects

| Project | Focus | Interfaces |
| :--- | :--- | :--- |
| **[PeakWhale™ Helm](https://github.com/PeakWhale/helm)** | Local-first research assistant over SQL databases and internal documents with read-only guards and source citations | CLI, FastAPI, Streamlit, MCP |
| **[PeakWhale™ Orca](https://github.com/PeakWhale/orca)** | Self-hosted real-time payment fraud detection with Isolation Forest anomaly scoring and plain-English explanations | FastAPI, Redpanda/Kafka, MLflow, Redis, MCP |
| **[PeakWhale™ Harbor](https://github.com/PeakWhale/harbor)** | Turns any CSV spreadsheet into a prediction web form, JSON API, batch scorer, and MCP server with 80% prediction intervals | CLI, Flask, MCP |
| **[PeakWhale™ Trident](https://github.com/PeakWhale/trident)** | Fail-safe AI + editable YAML rules triage engine that automatically escalates uncertain cases to a human reviewer | CLI, FastAPI, LangGraph, MCP |
| **[PeakWhale™ Berth](https://github.com/PeakWhale/berth)** | EV fleet depot charging planner powered by HiGHS linear optimization across time-of-use tariffs and site power caps | CLI, FastAPI, MCP |
| **[PeakWhale™ Pod](https://github.com/PeakWhale/pod)** | Domain-agnostic K-means cohort and regional clustering engine with plain-English segment profiles and outlier flags | CLI, FastAPI, MCP |
| **[PeakWhale™ Pilot](https://github.com/PeakWhale/pilot)** | Domain-agnostic outcome forecaster and early-warning engine with 80% prediction intervals, at-risk flags, and top driver explanations | CLI, FastAPI, MCP |
